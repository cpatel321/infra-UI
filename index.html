🗺️ OSM Road Processor

Process OpenStreetMap files - Extract roads, crop areas, export data

🚀 Quick Start

Get Started in 3 Steps:

  1. Run Setup: Double-click setup.bat to install everything
  2. Start Server: Double-click run.bat to launch the application
  3. Open Browser: Navigate to http://localhost:8000
📝 Note: A sample OSM file (sample_map.osm) is included for testing!

🔄 How It Works

Processing Workflow:

  1. Upload: Select and upload your .osm file
  2. Process: Extract roads from the file (removes buildings, etc.)
  3. Visualize: View roads on an interactive map
  4. Crop: Draw a rectangle to select specific area
  5. Download: Get your processed .osm file

🐛 Troubleshooting

⚠️ Common Issues:
  • Server won't start: Make sure virtual environment is activated
  • Can't upload files: Check that media directories exist
  • Map not loading: Ensure internet connection for map tiles
  • Import errors: Run setup.bat again

Run check.bat to verify your installation!
